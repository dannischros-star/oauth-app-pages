隐私权政策 / Privacy Policy

最后更新 / Last updated: 2026-11-04

适用范围 / Scope

本应用是一个仅由其所有者本人使用的个人自动化工具，不面向任何其他用户。

This application is a personal automation tool used only by its owner. It has no other users.

访问的数据 / Data accessed

本应用仅在所有者本人授权后，访问所有者本人 Google 账号中完成其自动化任务所需的数据，例如向本人发送邮件、读取本人"已发送"邮件以核验发送结果。

With the owner's own authorization, the app accesses only the data in the owner's own Google account that its automation needs, such as sending email to the owner and reading the owner's Sent mail to verify delivery.

使用、存储与共享 / Use, storage and sharing

  • 数据只在所有者本人的电脑上处理；授权凭据只保存在本机，不上传到任何第三方服务。
    Data is processed only on the owner's own computer; authorization credentials are stored locally and are not uploaded to any third-party service.
  • 不出售、不出租、不与任何第三方共享 Google 用户数据，也不用于广告。
    Google user data is never sold, rented, shared with third parties, or used for advertising.
  • 本应用对从 Google API 获得的信息的使用和传输，遵守 Google API 服务用户数据政策（包括"有限使用"要求）。
    The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

撤销授权 / Revoking access

所有者可随时在 Google 账号权限页面 撤销本应用的访问权限，并删除本机保存的凭据。

The owner can revoke access at any time on the Google Account permissions page and delete the locally stored credentials.

联系 / Contact

如有疑问，请通过本页面所在 GitHub 仓库的 Issues 联系。
For questions, please open an issue in the GitHub repository that hosts this page.
